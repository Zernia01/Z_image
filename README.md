# Zernia Image

> 빠르고 간편한 데스크톱 이미지 뷰어

**Version 0.1.5**

Zernia Image는 다양한 이미지를 편리하게 탐색하고 확인하기 위한 데스크톱 이미지 뷰어입니다.  
확대/축소, 이미지 이동, 즐겨찾기, 최근 기록, 사진만 보기, 간편 정보 확인 등의 기능을 제공합니다.

> 이 프로그램은 개발 과정에서 AI를 활용하여 제작되었습니다.

---

## 주요 기능

### 이미지 확대 / 축소

이미지를 보고 있는 상태에서

```text
Ctrl + 마우스 휠
```

을 사용하여 이미지를 확대하거나 축소할 수 있습니다.

- `Ctrl + 휠 위` : 확대
- `Ctrl + 휠 아래` : 축소

---

### 마우스 휠 이동

확대된 이미지에서는 마우스 휠을 이용하여 이미지를 이동할 수 있습니다.

이미지의 크기가 화면보다 클 경우 편리하게 이미지를 탐색할 수 있습니다.

---

### 즐겨찾기

자주 사용하는 사진이나 위치를 즐겨찾기로 관리할 수 있습니다.

설정에서 즐겨찾기 기능의 표시 여부를 변경할 수 있습니다.

```text
설정 → 즐겨찾기 표시 ON / OFF
```

---

### 최근 기록

최근에 열어본 이미지 또는 위치를 확인할 수 있습니다.

최근 기록 기능 역시 설정에서 활성화하거나 비활성화할 수 있습니다.

```text
설정 → 최근 기록 ON / OFF
```

개인정보 보호가 필요하거나 기록을 남기고 싶지 않은 경우 해당 기능을 끌 수 있습니다.

---

### 사진만 보기

현재 위치에서 이미지 파일만 표시하도록 설정할 수 있습니다.

사진과 관련 없는 파일을 숨기고 이미지 파일만 빠르게 확인할 때 사용할 수 있습니다.

설정에서 **자동 사진만 보기** 기능을 활성화하거나 비활성화할 수 있습니다.

```text
설정 → 자동 사진만 보기 ON / OFF
```

활성화하면 프로그램에서 폴더를 열었을 때 자동으로 사진 파일만 표시합니다.

---

### 간편 정보 보기

선택한 사진의 기본 정보를 빠르게 확인할 수 있습니다.

예를 들어 다음과 같은 정보를 확인할 수 있습니다.

- 파일 이름
- 이미지 형식
- 이미지 해상도
- 파일 크기
- 기본 이미지 정보

사진을 확인하면서 필요한 정보만 간단하게 볼 수 있도록 구성되어 있습니다.

---

## 조작 방법

| 조작 | 기능 |
|---|---|
| `Ctrl + 마우스 휠 위` | 이미지 확대 |
| `Ctrl + 마우스 휠 아래` | 이미지 축소 |
| `마우스 휠` | 이미지 이동 |
| 사진만 보기 | 이미지 파일만 표시 |
| 간편 정보 | 선택한 이미지 정보 확인 |

---

## 설정

Zernia Image에서는 일부 기능을 사용자의 취향에 맞게 변경할 수 있습니다.

현재 제공되는 주요 설정은 다음과 같습니다.

- 즐겨찾기 표시 ON / OFF
- 최근 기록 ON / OFF
- 자동 사진만 보기 ON / OFF

향후 프로그램 업데이트를 통해 추가 설정이 제공될 수 있습니다.
